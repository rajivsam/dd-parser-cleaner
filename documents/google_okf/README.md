# Google OKF Documentation Hub

This folder contains documentation and guidance for preparing `dd-parser-cleaner` outputs and metadata for Google / Open Knowledge Foundation (OKF) publication.

## Purpose

- Provide a dedicated space for OKF-compatible documentation, licensing guidance, and open-data packaging notes.
- Keep Google/OKF-specific workflow and artifact requirements separate from the core implementation docs.
- Enable consistent, auditable publication preparation for datasets, metadata, and project materials.

## Contents

- `google_okf_guide.md` — Guidance for Google OKF compatibility, data packaging, and documentation standards.
- `google_okf_project_setup.md` — Project setup notes for OKF publication, licensing, and data distribution.

## Usage

1. Read `google_okf_guide.md` to understand OKF expectations for open data and documentation.
2. Use `google_okf_project_setup.md` to record project-specific decisions, licensing, and publication artifacts.
3. Keep OKF publication notes in this directory so they remain separate from core project design docs.
